# TELO outreach package

This folder supports a first conversation with TELO about Just Haus as an early commercial customer and possible cold-climate field partner.

## Suggested sequence

1. Complete `assets-needed.md` and resolve every item in `claims-to-verify.md`.
2. Personalize `initial-email.md` for a named recipient.
3. Attach or link `field-partner-proposal.md` and the public concept page only after a final factual review.
4. Use `linkedin-message.md` only to reach the right person, not to make the full pitch.
5. If there is no response, send `follow-up-email.md` after roughly one week.
6. Prepare for a conversation with `first-call-talking-points.md`.

The unlisted page is `telo.html` in this repository and will resolve as `/telo.html` under the current GitHub Pages setup. It is intentionally not linked from the existing site and includes a `noindex` directive. This reduces casual discovery but is not access control; anyone with the URL can open or share it.
