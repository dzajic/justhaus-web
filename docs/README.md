# Just Haus knowledge base

This folder is the public source of truth for the company and its projects, and the place to plan a future project. It is plain Markdown so it reads on GitHub.

Everything in this folder is public. It holds company and project knowledge only. Contact is [hello@justha.us](mailto:hello@justha.us).

The site stays the public introduction. These notes are the working record, opened from a Notebook link in the footer. They stay out of the main navigation.

## How to use it

1. Read [company/overview.md](company/overview.md) and [company/voice-and-brand.md](company/voice-and-brand.md) before writing anything public.
2. For a new project, copy [projects/_template/README.md](projects/_template/README.md) to `docs/projects/<name>/README.md`.
3. Walk [principles/design-checklist.md](principles/design-checklist.md). On the project page, mark each rule applied, an exception, or n/a, and write the reason.
4. When a choice should stick, add a dated line to the project page and, if it is company-wide, to [decisions.md](decisions.md).
5. When a build teaches something, write the lesson on the project page. Leave costs, street addresses, and personal details out.

Why-lines on the checklist are draft rationale for Daniel to confirm. They are not measured results.
