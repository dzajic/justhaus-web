# Just Haus knowledge base

Working notes for the company and the projects, opened from Notebook in the footer, with contact at [hello@justha.us](mailto:hello@justha.us).

## Use

1. Read [company/overview.md](company/overview.md) and [company/voice-and-brand.md](company/voice-and-brand.md) before writing anything public.
2. For a new project, copy [projects/_template/README.md](projects/_template/README.md) to `docs/projects/<name>/README.md`.
3. Walk [principles/design-checklist.md](principles/design-checklist.md). On the project page, mark each rule applied, an exception, or n/a, and write the reason.
4. When a choice should stick, add a row on the project page and, if it is company-wide, in [decisions.md](decisions.md).
5. When a build teaches something, write the lesson on the project page. Leave costs, street addresses, and personal details out.
