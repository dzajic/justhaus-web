# Company

## Mission

Just Haus is a system for discovering better ways to build houses.

Each building is a home and a test. What it teaches can change the next one.

## Practice

Just Haus LLC is a design and build practice in the White Mountains of New Hampshire. The work is close to real buildings and a real winter.

Contact is [hello@justha.us](mailto:hello@justha.us).

## Offer

The goals are a lower cost, a lower CO2 footprint, and a faster build. Those are goals. They are not measured results, and this record does not publish performance figures. When a project is measured, the results can be shared as they come in.

A future project can start as a conversation. There is no price list and no fixed service menu. Have a house in mind? Write to [hello@justha.us](mailto:hello@justha.us).

## Project naming

The first project is Alpha. Later work may take the next Greek letters. That naming is a direction for now, and the sequence can still grow.
