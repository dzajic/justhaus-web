# Project decisions

This file records durable decisions so future contributors do not have to infer
them from page history.

## Keep the website static

The site is small, fast, and published as standalone HTML and CSS through
GitHub Pages. Do not introduce a framework or build system without a concrete
need and explicit approval.

## The public site documents the company

The pages are about Just Haus and its philosophy. Just Haus Alpha is the first
project, not the whole site. The site does not sell services or take
commissions.

## TELO is not on the site

The TELO field-partner pages, their images, and the outreach notes were
removed. Do not restore them unless Daniel asks.
