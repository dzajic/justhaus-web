# Project brief

Just Haus is a system for discovering better ways to build houses, practiced in the White Mountains and tied to real buildings.

| Topic | Note |
| --- | --- |
| Practice | Small. Alpha is the first project. Each building is a home and a test, and the lesson is meant to change the next one. |
| Compactness | A way to use less material, disturb less land, and simplify energy, construction, and cost, while keeping comfort and utility. |
| Site | Documents the company, the philosophy, and the work. |
| Voice | Quiet, direct, and specific. Clear to a nontechnical reader. Candid about what is still being tested. |
| Hold for later | Hype, luxury language, generic sustainability claims, costs, specifications, and performance figures. |
| Look | Warm char ground, birch type, honey for hairlines and light. Phone first. Real construction photographs. Generous space, fine rules, a quiet linen grain. |
